# Публичная страница Atlas

Адрес: https://atlas.prism-news.xyz/about. Страница доступна без входа; личный интерфейс по `/` по-прежнему требует авторизацию.

`frontend/src/LandingPage.tsx` содержит русские тексты и иллюстративные примеры, `landing.css` — адаптивный дизайн. Отдельный `about.tsx` не импортирует owner API. Vite собирает `index.html` и `about.html`; nginx направляет `/about` на самостоятельный entry. `/about/` перенаправляется на `/about`. В dev `/about` обслуживается через безопасную публичную ветку main.tsx.

Вкладки — исключительно примеры. Они не включают микрофон, не запускают задачи и не вызывают LLM. Голос описывается как функция клиента Windows; Telegram и внешние интеграции требуют настройки. Публичная страница не раскрывает частные настройки, устройства, выбранные модели и ключи владельца. Стили и графика локальные, сторонних трекеров и шрифтов нет.

Проверка: `npm run build`, `npm test`, из корня `.venv\Scripts\python.exe scripts/check_local_e2e.py`. Публичный HTTPS smoke: из frontend `node scripts/check-about.mjs`; для другого стенда задать `ATLAS_PUBLIC_ABOUT_URL`. Smoke не вводит пароль и не запускает платные запросы; генерирует desktop/mobile скриншоты в `.sessions`, проверяет CSP/JS, отсутствие API-запросов и сохранение формы входа.

Обновление `ops/voice-rollout/about-web.sh` меняет только web, проверяет SHA-256 архива, сохраняет предыдущий образ и frontend-исходники. Не применять повторно с тем же release-каталогом. При недоступности health/about восстанавливается прежний образ; исходники для ручного восстановления остаются в `pre-about-web-source.tar.gz`. Скрипт запускать из сохранённого файла, не из pipe архива в bash.
