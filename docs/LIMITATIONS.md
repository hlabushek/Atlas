# Известные ограничения
- Реализованы этапы 0–2 и ограниченный проверенный объём 3/4. Защищённый read-only Desktop Companion реализован; публичный GitHub connector, расширенная память и production эксплуатация впереди.
- Инструменты: встроенные memory.search/notes.create, demo diary и явно выбранные remote read-only MCP/REST. Внешние записи/non-atomic действия запрещены. UNKNOWN ставит задачу на PAUSED и запрещает resume; сейчас можно отменить, внешний reconciliation UI ещё не нужен и не реализован.
- LangGraph управляет шагами; долговременные checkpoints — SQL task/tool_calls, не InMemorySaver или отдельный LangGraph checkpoint backend. DB действие, проверка и checkpoint атомарны.
- План ограничен 8 шагами; ошибки read/DB-atomic инструментов повторяются до 3 попыток. Автоматическое модельное replanning, условные планы и tool calling внутри обычного диалога ещё не реализованы. Инструментальную задачу запускают отдельно в Активности.
- Demo планировщик фиксирован: поиск памяти → заметка с результатом. Это не интеллект LLM. Ollama/OpenAI-compatible ответ и JSON план имеют protocol тесты; живые модели не проверялись.
- Месячные и дневные UTC token/cost лимиты, per-task cost cap для чата и планировщика и persistent ledger реализованы. Лимиты проверяются на резерве до HTTP; UNKNOWN удерживает резерв и блокирует денежный cap. Embedding запросы не привязаны к задаче и ограничены только суточным/месячным бюджетом. Повтор генерации после crash может вызвать новый платный запрос с отдельным резервом.
- pgvector используется для опциональных 768-dimensional embeddings. Redis не является очередью jobs; SQL — источник durable задач. Нет ANN/HNSW индекса.
- PWA, opt-in Web Push, bounded text uploads и browser Speech реализованы. Telegram voice использует опциональный RouterAI STT с отдельным RUB ledger. Нет streaming токенов, PDF/Office parsing и серверного TTS. Live push, микрофон, STT и Telegram не проверены.
- Словарный поиск ограничен 1000 последними записями; опциональный vector поиск добавляет ближайшие 30. Конфликты только для явно подтверждённых одинаковых ключей/разных значений. Нет автоматического определения противоречий по смыслу/графа знаний. Live embedding model не настроена; Выбор модели/провайдера теперь меняется через настройки и изолирует vector namespace; cache при смене весов под тем же model name надо обслужить отдельно.
- Удаление Memory исключает её из новых поисков. Цитаты в сообщениях, сохранённых результатах, approvals и заметках остаются; полного удаления всех пользовательских данных пока нет.
- Server-side session revoke и настоящие PostgreSQL dump/restore drills реализованы. Нет универсального encrypted vault. Секреты — env/отдельные зашифрованные external sessions; фильтр не распознаёт все неизвестные секреты.
- Login rate limit per-process. HTTPS/production credential overlay и локальные ops checks реализованы. Нужны публичный домен/сертификаты/renewal/firewall, remote rollout и операторское обслуживание.
- SQLite dev и PostgreSQL Compose — отдельные профили данных, не синхронизированные интерфейсы.
- После первоначальной ошибки тестовой изоляции в Compose demo DB остались тестовые записи; исправленная fixture использует только собственную схему и проверяет её пустоту. E2E/restart drill также создают помеченные данные.

- Живой Telegram не проверен: token/owner ID задаёт владелец локально. Текст и небольшие UTF-8 TXT/MD/CSV/JSON файлы (до 64 КиБ) проходят через общую очередь; бинарные/PDF/Office файлы не поддерживаются. Голос до 2 минут/5 МиБ расшифровывается RouterAI; расходы ведутся отдельным RUB ledger с настраиваемыми дневным/месячным пределами. Неизвестный исход платного STT запроса удерживает резерв. Тариф по умолчанию — 41 коп./мин для Universal-3.5 Pro; перед постоянным использованием сверяйте актуальный тариф и при необходимости задайте `ATLAS_TELEGRAM_STT_KOPECKS_PER_MINUTE`. Платная и живая Telegram проверка не выполнялась. UNKNOWN доставок не повторяется автоматически.
- Проактивность — opt-in и фиксированные правила. Нет LLM оценки уместности, календаря или регулярных задач. UI не выбирает явный initiative_id при нескольких вопросах в одном разговоре; backend прекращает повтор только при однозначном ответе. Смена канала не переносит уже зарезервированную outbox доставку.
- Установка навыков не запускает сторонний код: нет OS sandbox/stdin MCP/пакетов arbitrary runtime. Доверие readOnlyHint и endpoint остаётся на владельце. Allowlist hostname не ограничивает порт и не изолирует злонамеренный доверенный сервер. Внешняя сеть требует approval каждого вызова.
- Раздел «Дневник» и расписание по-прежнему используют явно помеченный demo provider; generic browser sources доступны отдельно через «Интеграции». Для них AI создаёт только CSS-рецепты по sanitized DOM outline, не произвольный код; владелец должен проверить предложенные селекторы. Импортируются только видимые текстовые поля выбранных элементов, максимум 500 записей и 250 КБ за пакет.
- Browser auto-sync выключен по умолчанию. Если владелец включает его, Chrome просит разрешение для отдельного HTTPS домена, затем расширение синхронизирует только совпавшие открытые вкладки при загрузке и раз в 15 минут. Пока компьютер/Chrome выключен, обновления нет. CAPTCHA/MFA/bot protection не обходятся; логин остаётся ручным. Раздел «Дневник» не преобразует generic source records в assignments.
- Настоящий школьный API/аккаунт и live импорт не проверены. Учебный план остаётся детерминированным, не оценкой знаний от LLM.

- Desktop: read_text/list, create_text (только новый ограниченный текстовый файл) и launch_file (документ через локально разрешённое приложение) по outbound mTLS. Нет редактирования/удаления, произвольных команд ОС или browser automation. Не реализованы MSI/GUI/служба/автообновление и PKI/CRL/OCSP rotation. Production gateway запущен отдельным Compose overlay; локальный Windows процесс связан с VPS.
- Local config и companion process — доверенная граница владельца. Сервер проверяет hash/identity/scoped approval и актуальные grants, но не может независимо прочитать удалённый диск. После последнего permit остаётся окно до фактического чтения; revoke запрещает публикацию результата, но не отменяет уже прочитанные локально байты. UNKNOWN не переотправляется, создаётся новая задача после ручной проверки.
- Windows filesystem защита запрещает все reparse points, включая часть OneDrive каталогов. Hard links и файлы с несколькими links запрещены. SQLite профиль не предназначен для конкурирующего production исполнения: сериализация policy row проверена на PostgreSQL.

## Граница этапов 6/7
GitHub — только публичные метаданные, без OAuth/private/write/issues workflow. Внешние API доступны по configured owner grants. Embeddings, push, actual LLM, Telegram и школьный сайт не настроены в рабочей конфигурации; протокольные fixtures не выдаются за live интеграции.
Push subscription capabilities и embeddings приватны; защищайте volumes/backups/OS ACL. Generic push не содержит текста инициативы, UNKNOWN не повторяется. Offline PWA предоставляет оболочку, не доступ к истории без сервера.
Локальный load baseline не измеряет производительность LLM, внешних сервисов или production VPS. TLS drill использует локальный доверенный сертификат, не публичный CA. Для production VPS включены encrypted backup, restore schedule и Telegram-оповещение о базовых сбоях; зашифрованная копия и ключ также переносятся на Windows, когда компьютер включён. Нет automatic failover/tracing, MFA, image digest policy и полного CVE audit backend. Исходное большое ТЗ остаётся незавершённым в этих границах; см. EXTENDED_MEMORY.md и OPERATIONS.md.

## Настраиваемые модели
Роли main/planner/embedding, выбор в Настройках, каталог/ручной ID, persistent preference и Task snapshot реализованы. Включены рекомендуемые RouterAI profiles; ключи не заданы, поэтому реальных LLM/embedding запросов не проверено. Сложный профиль выбирается владельцем в чате или используется для agent planner; автоматического определения сложности/fallback нет. Тарифы ролей ручные, в микроUSD; автоматического импорта рублёвых цен/курса нет. Qwen endpoint должен действительно поддерживать 768; неподходящий ответ отклоняется. PlusVibe остаётся непроверенным вариантом без live ключа.
