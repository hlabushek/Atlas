# Atlas · Универсальные источники Chrome

Расширение использует `activeTab`: оно читает только открытую вами HTTPS страницу после нажатия кнопки. Для входа используется обычная вкладка сайта. Пароли, поля форм, скрытое содержимое и произвольные вкладки не копируются. Cookies передаются на VPS только отдельной кнопкой после разрешения Chrome и просмотра их имён; значения не показываются и не отправляются модели.

## Добавление источника

1. Обновите распакованное расширение в Chrome: `chrome://extensions` → карточка Atlas → кнопка обновления. В Manifest V3 локальной установке Chrome может потребоваться удалить старую карточку и загрузить эту папку заново; обновление перезапускает worker расширения.
2. Откройте страницу сайта после обычного входа и нажмите значок Atlas.
3. Опишите цель своими словами и нажмите «Исследовать страницу и предложить адаптер». В настроенную модель Atlas отправятся цель, адрес/название страницы, заголовки, подписи, типы элементов, классы, сведения об изображениях и ссылки на видимые страницы того же сайта. Значения записей и содержимое полей формы не отправляются.
4. Связанные страницы можно открыть из списка и исследовать отдельно. Переход выполняет владелец; расширение не обходит сайт самостоятельно.
5. Проверьте черновик JSON и нажмите «Показать данные до сохранения». Просмотр покажет число найденных записей и первые три записи. Затем сохраните источник. Для уже сохранённой страницы рецепт можно доработать новым запросом, не удаляя прежние записи; ключ записей остаётся прежним.
6. На нужной странице нажмите «Загрузить данные сейчас». Расширение читает видимые значения только выбранных элементов, отправляет пакет в Atlas, где записи можно посмотреть в разделе «Интеграции». Поле `image_url` извлекает HTTPS адрес изображения без параметров; сама фотография не копируется в Atlas.

Для каждого сохранённого источника отдельно можно включить автообновление в Chrome. Chrome запросит разрешение на один HTTPS-домен. После этого открытая страница синхронизируется при загрузке и раз в 15 минут, пока браузер работает. Отключите источник в Atlas, чтобы отозвать чтение агентом и остановить автоимпорт; разрешение Chrome можно дополнительно отозвать на странице расширений.

Для серверного сбора владелец VPS добавляет hostname сайта в `ATLAS_INTEGRATION_HOSTS` и задаёт `ATLAS_CONNECTOR_SESSION_KEY` для сайтов за входом. В разделе «Интеграции» сначала нажмите «Проверить страницу с VPS»: первые три записи покажут, подходит ли рецепт к странице, которую видит сервер. Для страницы за входом можно передать cookies из Chrome отдельной кнопкой или включить режим Chromium на VPS и пройти вход через его снимки. Сессия шифруется и живёт не более 7 дней. После этого можно включить ежедневный сбор. Scheduler выполняет его при выключенном компьютере; сетевые запросы ограничены сайтом, а результат извлечения — 1 МБ. Ошибка отображается как `FAILED`, сохранённые записи не удаляются.

Источник доступен ИИ-агенту только после отдельного разрешения в Atlas. Даже после этого каждый вызов чтения требует подтверждения. Отключение источника отзывает доступ агента; сохранённые записи остаются в базе.

## Границы

- Это расширяемый универсальный каркас, а не адаптер, который гарантированно понимает любой сайт. ИИ может ошибиться в селекторах; владелец проверяет их на открытой странице перед сохранением.
- Расширение не обходит CAPTCHA, MFA, bot protection или paywall. Войдите вручную. Если сайт блокирует чтение страницы, нужен его официальный API или отдельное согласованное подключение.
- Автообновление через Chrome работает только при открытой странице в работающем браузере. Серверное расписание работает отдельно; сайты с JavaScript-рендерингом могут не подойти серверному сбору.
- На VPS есть интерактивный браузер для ручного входа на исходный домен. Вход через другой домен, popup, CAPTCHA-картинки и обязательный sessionStorage могут не сработать. Связанные страницы открываются по выбору владельца, без автоматического обхода.
- Импортированные значения рассматриваются как недоверенные данные. Они не исполняются. Cookie/credential-like значения отклоняются, записи ограничены по размеру.
- Текущий рецепт читает текстовые поля по селекторам и ограничен 500 записями за запуск. Действия записи поддерживают только точные JSON-запросы с независимой проверкой; файлы, произвольные скрипты и запись через DOM не поддерживаются.

## Локальная проверка

Проверить синтаксис без браузерных привилегий: `node --check popup.js`. Бэкенд тесты: `python -m pytest tests/test_universal_connectors.py` из `backend`.
